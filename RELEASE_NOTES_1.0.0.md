# AfterWIP 1.0.0 — by Artyns

AfterWIP 1.0 connects Adobe After Effects to AI assistants such as ChatGPT and
Claude through MCP.

## What's new

- **Free and Pro plans.** Sign in with Google and start on Free: up to 10
  successful operations per day (resets at 00:00 UTC, shown in your local time).
  Operations that After Effects reports as failed are not counted. Pro removes
  the daily limit for normal use.
- **No invitation needed.** Any Google account can sign in; Beta Access is a
  separate, optional permission.
- **Account card in the panel.** Your Google account, plan, remaining operations,
  Beta Access and an Upgrade to Pro link.
- **Faster commands.** About 1 second per command, down from several seconds.
- **Clearer messages** for limits, sign-in, devices and After Effects refusals.
- **New welcome animation** and AfterWIP — by Artyns branding throughout.
- **License agreement.** The installers now show the AfterWIP End User License
  Agreement. Open-source notices are kept in THIRD-PARTY-NOTICES and LICENSE.

## Install

- Windows 10/11 x64: run the EXE. Windows may show SmartScreen for a new
  installer; choose **More info → Run anyway**.
- macOS 13.5+ (Apple silicon and Intel): open the PKG. If macOS blocks it, open
  **System Settings → Privacy & Security → Open Anyway**.

Existing AfterWIP 0.3.x installations are upgraded in place.
